# 學生、課程與成績管理系統

使用 PHP、MySQL、HTML、CSS 與 jQuery 製作的簡易選課資料管理系統，可管理學生、課程、修課名單及成績。

## 環境需求

- Windows 上的 XAMPP
- Apache 與 MySQL（MariaDB）
- PHP PDO MySQL 擴充功能
- 可連上網路以載入 jQuery CDN

## 安裝與啟動

1. 將本資料夾放在 XAMPP 的 `htdocs` 目錄下。若使用目前的資料夾位置，應為 `C:\xampp\htdocs\ITSA比賽`。
2. 開啟 XAMPP Control Panel，啟動 **Apache** 和 **MySQL**。
3. 在瀏覽器開啟 `http://localhost/phpmyadmin/`。
4. 選擇「匯入」，選取本資料夾的 `init.sql`，再按「匯入」。此 SQL 會建立 `選課系統` 資料庫、資料表和範例資料。
5. 確認 `db.php` 的資料庫連線設定符合你的 XAMPP 設定。預設值如下：

   - 主機：`localhost`
   - 資料庫：`選課系統`
   - 帳號：`root`
   - 密碼：空白

6. 用瀏覽器開啟 `http://localhost/ITSA比賽/`。

請透過 Apache 網址開啟系統，不要直接雙擊 `index.html`；前端需要向 PHP 的 `api.php` 發送請求。

## 功能操作

- **學生管理**：依科系篩選學生，新增、編輯或刪除學生資料。
- **課程管理**：依授課老師或課程關鍵字查詢，新增、編輯或刪除課程；點選選課人數可查看修課學生及成績。
- **課程成績管理**：依學生姓名、授課老師或課程名稱篩選修課資料，新增選課成績、修改成績或刪除修課資料。

系統沒有登入功能；開啟首頁後即可操作。

## 資料與注意事項

- `init.sql` 內含系所、老師、課程、學生及選課範例資料。若要重新匯入，請先在 phpMyAdmin 備份或移除現有資料；SQL 的範例資料不是以重複匯入為設計目的。
- 學生與課程的刪除受選課資料的外鍵限制。刪除有選課紀錄的學生前，請先到「課程成績管理」刪除該學生的修課資料；有學生選修的課程則無法刪除。
- 若資料庫帳號或密碼不是預設值，請修改 `db.php` 的 `$user` 和 `$pass`。

## 檔案用途

- `index.html`：管理介面
- `team003.css`：頁面樣式
- `team003.js`：前端互動及資料載入
- `api.php`：學生、課程及成績的 API
- `db.php`：MySQL 連線設定
- `init.sql`：建立資料庫、資料表及範例資料

## 常見問題

- **顯示資料庫連線錯誤**：確認 XAMPP 的 MySQL 正在執行，且 `db.php` 的資料庫名稱、帳號和密碼正確。
- **頁面打開但資料沒有載入**：確認 Apache 正在執行，網址使用 `http://localhost/ITSA比賽/`，並已匯入 `init.sql`。
- **新增資料失敗**：檢查必要欄位是否已填寫，以及學生學號、課程代號或修課組合是否已存在；資料表對這些欄位設有主鍵限制。
- **樣式或互動沒有正常載入**：確認網路可連線，因為 jQuery 是從 CDN 載入。
